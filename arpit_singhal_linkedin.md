## Projects (from GitHub — github.com/arpitsinghal98)

### Half-Life — *featured, most recent*
**Private repo** · JavaScript/Node/Express, vanilla JS frontend, Anthropic SDK (claude-opus-5) · Built for the **Claude Impact Lab** hackathon (Jul 31)

An interactive tool that scores a person's described work week task-by-task for AI-automation exposure, rather than judging whole jobs. Users describe their week → Claude decomposes it into 12–22 tasks → each is scored on a 6-axis rubric (structure, verifiability, digital context, error tolerance, disembodiment, impersonality) → deterministic code computes an "exposure %" and a "half-life" (the month cumulative displaceable hours cross 50%) → generates paste-ready prompts to hand off the most automatable tasks. Includes a live-streaming card UI (SSE), a shared anonymized leaderboard, and a 3-minute demo script.

- Notable design choice: the LLM only supplies qualitative sub-scores; all arithmetic is done in code (`server/scoring.js`, ~40 lines) for auditability — "if you disagree with a number, argue with the specific axis, not a black box."
- Stack: Node 20+, Express, Anthropic SDK, `POST /api/ledger` (SSE streaming), `POST /api/plan` (structured JSON output), `POST /api/board`.
- **Strongest recent portfolio piece** — shows product thinking + LLM system design, not just CRUD.
